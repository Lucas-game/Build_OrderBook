# data/：数据放在这里

这个文件夹放统一格式后的 L2 样本数据。**数据文件（.csv）不随仓库发布**，仓库里只有这份说明。

每只证券一天一个文件夹，命名为 `交易所_代码_日期`，里面固定三个文件：

| 文件 | 内容 |
| --- | --- |
| `orders.csv` | 逐笔委托（上交所的撤单、状态记录也在这里） |
| `trades.csv` | 逐笔成交（深交所的撤单也在这里） |
| `snapshots.csv` | 交易所十档快照，用来对账 |

本项目用到的五份样本：

```
data/
├── SZ_000001_20260302/   平安银行，深交所主板
├── SZ_300750_20220426/   宁德时代，深交所创业板
├── SH_603353_20260302/   和顺石油，上交所主板
├── SH_110093_20260302/   神马转债，上交所可转债
└── SH_518880_20260302/   黄金 ETF，上交所 ETF
```

各列的含义、深沪差异和已知数据问题见仓库根目录的 `README_数据说明.md`。代码（`lob_rebuild/src/`）默认从这里读数据。
